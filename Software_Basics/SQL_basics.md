## What This Room Covered

This room explored how modern businesses and applications track, manage, and audit their processes using **SQL (Structured Query Language)** databases.

## Terms I Learned

| Concept / Command | Purpose | Quick Example |
| :--- | :--- | :--- |
| **Tables** | Organizes data neatly into rows and columns (similar to a spreadsheet). | `Users`, `Orders` |
| `SELECT * FROM` | Retrieves **all** columns and data from a specific table. | `SELECT * FROM users;` |
| `WHERE` | Filters results to only show rows that match a specific condition. | `WHERE age > 18` |
| `ORDER BY` | Sorts the resulting data (ascending by default, or descending using `DESC`). | `ORDER BY signup_date DESC` |


## What Actually Clicked

Using SQL completely changes how you think about data. Instead of manually digging through massive files, databases make it incredibly 
efficient to classify, search, and manipulate millions of records instantly just by writing a simple, logical command.
