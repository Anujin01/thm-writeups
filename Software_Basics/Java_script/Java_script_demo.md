## Terms i learned

* **Variables:** Named containers used to store data values that can be dynamically referenced, updated, and manipulated throughout a program.
  
* **Constants:** Fixed variables declared to hold values that cannot be reassigned or changed after their initial definition.

## What Actually Clicked

While Python and JavaScript share many conceptual similarities (like using conditional logic and loops), I found JavaScript to be slightly more challenging.
This is primarily due to its syntax differences—such as the frequent use of curly braces `{}` for code blocks, parentheses `()` for conditions, and explicit 
variable declarations (`let`, `const`, `var`), whereas Python relies heavily on clean indentation and simpler variable assignment.
