## What This Room Covered

This room covered how to learn to search the internet and use specialized services and technical documents for information

## Tools i learned

* **Shodan** - A specialized search engine for the Internet of Things (IoT). Shodan's crawlers run continuously to build a massive database, delivering requested metadata in seconds.
  
* **VirusTotal** - An aggregation service that works with over 70 antivirus engines and website scanners. It analyzes files, hashes, URLs, or domains to provide comprehensive security reports.

## What Actually Clicked

There is an incredible abundance of open-source tools available across the internet to measure and analyze threats; the real skill lies in learning how to use them effectively and efficiently.
